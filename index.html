    사용법과 단축키

    1. 수업을 하나 만들고, 클립 추가로 유튜브 주소를 붙여넣습니다.

    3. 수업 시간에는 왼쪽 목록에서 클립을 누르기만 하면 해당 구간이 재생됩니다.
    4. 내보내기로 받은 JSON 파일을 다른 컴퓨터에서 가져오기 하면 그대로 옮겨집니다.
