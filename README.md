# Teach_UtoV — 수업용 유튜브 구간 재생기

수업에서 보여 줄 유튜브 영상의 **구간(시작~끝)** 을 미리 기록해 두고,
수업 시간에는 목록에서 클릭 한 번으로 그 구간부터 바로 재생하는 웹앱입니다.

영상을 내려받지 않습니다. 유튜브 공식 **IFrame Player API** 로 유튜브가 그 자리에서
재생하도록 할 뿐이므로 복제가 일어나지 않고, 저작권법과 유튜브 이용약관을 건드리지 않습니다.
조회수와 광고 수익도 원저작자에게 그대로 돌아갑니다.

## 무엇이 되나요

- **수업 단위 정리** — 차시별로 수업을 만들고 그 안에 클립을 순서대로 모아 둡니다.
- **구간 지정** — 유튜브 주소를 붙여넣고, 플레이어를 돌려 보며 `현재 위치` 버튼으로 시작·끝을 찍습니다.
- **한 번에 재생** — 목록에서 클립을 누르면 지정한 지점부터 재생되고, 끝 지점에서 자동으로 멈춥니다.
- **수업용 편의 기능** — 구간 반복, 끝나면 다음 클립 자동 재생, 재생 속도, 클립별 메모.
- **단축키** — 스페이스(재생/정지), `R`(구간 처음으로), `←`/`→`(5초), `Shift+←`/`→`(이전·다음 클립), `1`~`9`(번호 클립).
- **백업과 이동** — JSON 파일로 내보내고 다른 컴퓨터에서 가져오면 그대로 옮겨집니다.

## 실행하기

Node.js 18 이상이 필요합니다. 별도 의존성 설치는 없습니다.

```bash
npm start
```

그다음 브라우저에서 `http://localhost:4173` 을 엽니다.

> `index.html` 을 파일로 직접 열면(`file://`) 유튜브 플레이어가 동작하지 않습니다.
> 반드시 위 명령으로 띄우거나, 정적 호스팅(GitHub Pages 등)에 올려서 사용하세요.

포트를 바꾸려면 `PORT=8080 npm start` 처럼 지정합니다.

## 쓰는 순서

1. **＋ 새 수업** 으로 차시를 하나 만듭니다.
2. **＋ 클립 추가** 를 누르고 유튜브 주소를 붙여넣습니다. 주소에 `t=` 가 있으면 시작 시각이 자동으로 채워집니다.
3. 아래 플레이어를 돌려 보며 **현재 위치** 버튼으로 시작과 끝을 찍고, 제목·메모를 적어 저장합니다.
4. 수업 시간에는 왼쪽 목록을 클릭하거나 숫자 키를 눌러 재생합니다.

데이터는 브라우저의 `localStorage` 에 저장됩니다. 브라우저 데이터를 지우면 함께 사라지므로,
정리한 수업은 **내보내기** 로 JSON 백업을 받아 두는 편이 안전합니다.

## 구조

```
index.html          화면 마크업
css/styles.css      스타일 (밝게/어둡게)
js/utils.js         시간 파싱·표기, 유튜브 주소 해석
js/store.js         수업·클립 데이터와 localStorage 저장
js/player.js        YouTube IFrame Player API 감싸개 (구간 감시 포함)
js/ui.js            화면 그리기와 이벤트 처리
js/app.js           부팅
scripts/serve.mjs   의존성 없는 로컬 정적 서버
```

빌드 도구 없이 순수 HTML/CSS/JS로 되어 있어, 파일을 그대로 정적 호스팅에 올릴 수 있습니다.

## 앞으로

- 클립 드래그로 순서 바꾸기
- 수업 화면 전용 큰 보기(발표 모드)
- 필요해지면 Electron 으로 감싸 데스크톱 앱으로 배포

## 왜 새로 만들었나

이 저장소의 전신인 **UtoV** 는 유튜브 영상의 구간을 내려받는 도구였습니다.
내려받기는 복제에 해당해 저작권 문제가 생길 수 있어, 같은 필요(수업에서 필요한 구간만 보여 주기)를
**복제 없이** 해결하는 방향으로 방식을 바꾸었습니다.
