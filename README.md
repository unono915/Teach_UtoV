# Teach_UtoV — 수업용 유튜브 구간 재생기

수업에서 보여 줄 유튜브 영상의 **구간(시작~끝)** 을 미리 기록해 두고,
수업 시간에는 목록에서 클릭 한 번으로 그 구간부터 바로 재생하는 도구입니다.
웹에서 바로 쓸 수도 있고, 윈도우 프로그램으로 설치해 쓸 수도 있습니다.

영상을 내려받지 않습니다. 유튜브 공식 **IFrame Player API** 로 유튜브가 그 자리에서
재생하도록 할 뿐이므로 복제가 일어나지 않고, 저작권법과 유튜브 이용약관을 건드리지 않습니다.
조회수와 광고 수익도 원저작자에게 그대로 돌아갑니다.

- 소개 페이지: `docs/index.html` → GitHub Pages
- 웹앱: `docs/app/` → Pages 에서 `/app/`
- 데스크톱: `electron/` → 윈도우 무설치·설치본

## 무엇이 되나요

- **묶음 > 수업 > 클립** — 과목이나 학기를 묶음으로 만들고, 그 안에 차시별 수업을, 수업 안에 클립을 담습니다.
- **구간 지정** — 유튜브 주소를 붙여넣고, 플레이어를 돌려 보며 `현재 위치` 버튼으로 시작·끝을 찍습니다.
- **한 번에 재생** — 목록에서 클립을 누르면 지정한 지점부터 재생되고, 끝 지점에서 자동으로 멈춥니다.
- **끌어서 정렬** — 수업과 클립 목록의 순서를 마우스로 끌어 바꿉니다.
- **발표 모드** — 목록과 편집 칸을 감추고 영상만 크게. 전체 화면으로 전환됩니다. (`P` / `Esc`)
- **수업용 편의 기능** — 구간 반복, 끝나면 다음 클립 자동 재생, 재생 속도, 클립별 메모.
- **단축키** — `Space`(재생/정지), `R`(구간 처음), `←`/`→`(5초), `Shift+←`/`→`(이전·다음 클립), `1`~`9`(번호 클립), `L`(반복), `N`(새 클립).
- **백업과 이동** — JSON 파일로 내보내고 다른 컴퓨터에서 가져오면 그대로 옮겨집니다.

## 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm start
```

브라우저에서 `http://localhost:4173` 을 엽니다. 소개 페이지까지 함께 보려면 `npm run site`
(`http://localhost:4174`, 웹앱은 `/app/`).

> `index.html` 을 파일로 직접 열면(`file://`) 유튜브 플레이어가 동작하지 않습니다.
> 위 명령으로 띄우거나, 정적 호스팅(GitHub Pages 등)에 올려서 사용하세요.

### 데스크톱 앱

```bash
npm install
npm run app
```

윈도우용 실행 파일을 만들려면:

```bash
npm run dist
```

`release/Teach_UtoV-portable.exe`(무설치)와 `release/Teach_UtoV-setup.exe`(설치본)가 나옵니다.

데스크톱 앱은 창 안에서 작은 http 서버를 띄우고 거기에 접속합니다. 유튜브 플레이어가
`file://` 에서 동작하지 않기 때문입니다. 저장한 목록이 계속 보이도록 포트를 `47317` 로 고정합니다.

## GitHub Pages

저장소 설정에서 **Settings → Pages → Source: Deploy from a branch → `main` / `/docs`** 로 지정하면
`docs/` 가 그대로 올라갑니다.

- `https://unono915.github.io/Teach_UtoV/` — 소개와 내려받기 페이지
- `https://unono915.github.io/Teach_UtoV/app/` — 웹앱

내려받기 단추는 GitHub Releases 의 최신 파일을 가리킵니다.
`npm run dist` 로 만든 두 실행 파일을 릴리스에 올리면 링크가 살아납니다.

## 쓰는 순서

1. **＋ 새 묶음** 으로 과목이나 학기를 만듭니다. (묶음 없이 수업만 만들어도 됩니다.)
2. **＋ 새 수업** 으로 차시를 만듭니다.
3. **＋ 클립 추가** 를 누르고 유튜브 주소를 붙여넣습니다. 주소에 `t=` 가 있으면 시작 시각이 자동으로 채워집니다.
4. 플레이어를 돌려 보며 **현재 위치** 버튼으로 시작과 끝을 찍고, 제목·메모를 적어 저장합니다.
5. 수업 시간에는 목록을 클릭하거나 숫자 키를 누르고, **발표 모드**로 크게 띄웁니다.

데이터는 브라우저의 `localStorage` 에 저장됩니다. 브라우저 데이터를 지우면 함께 사라지므로,
정리한 목록은 **내보내기** 로 JSON 백업을 받아 두는 편이 안전합니다.

## 구조

```
docs/index.html            소개·내려받기 페이지 (GitHub Pages)
docs/styles.css            소개 페이지 스타일
docs/app/                  웹앱 본체
  index.html               화면 마크업
  css/styles.css           스타일 (밝게/어둡게, 발표 모드)
  js/utils.js              시간 파싱·표기, 유튜브 주소 해석
  js/store.js              묶음·수업·클립 데이터와 localStorage 저장
  js/player.js             YouTube IFrame Player API 감싸개 (구간 감시 포함)
  js/ui.js                 화면 그리기와 이벤트 처리
  js/app.js                부팅
electron/main.js           데스크톱 앱 (내장 http 서버 + 창)
scripts/static-server.mjs  의존성 없는 정적 서버 (개발·데스크톱 공용)
scripts/serve.mjs          웹앱 미리보기
scripts/serve-site.mjs     소개 페이지 미리보기
scripts/make-icon.mjs      앱 아이콘 생성
```

웹앱은 빌드 도구 없이 순수 HTML/CSS/JS 로 되어 있어, 파일을 그대로 정적 호스팅에 올릴 수 있습니다.

## 저장 형식

내보내기 파일은 다음과 같은 모양입니다. (스키마 v2)

```json
{
  "app": "Teach_UtoV",
  "version": 2,
  "collections": [{ "id": "col-…", "title": "2학년 통합과학" }],
  "lessons": [{
    "id": "lesson-…",
    "collectionId": "col-…",
    "title": "4차시 · 생명 시스템",
    "clips": [{ "videoId": "…", "title": "ATP 설명", "start": 252, "end": 400, "note": "" }]
  }]
}
```

묶음이 없던 v1 파일도 그대로 불러올 수 있습니다. 수업이 "묶음 없음" 상태로 들어옵니다.

## 앞으로

- 수업 단위 공유 링크(주소에 목록을 담아 전달)
- 맥·리눅스 빌드

## 왜 새로 만들었나

이 저장소의 전신인 **UtoV** 는 유튜브 영상의 구간을 내려받는 도구였습니다.
내려받기는 복제에 해당해 저작권 문제가 생길 수 있어, 같은 필요(수업에서 필요한 구간만 보여 주기)를
**복제 없이** 해결하는 방향으로 방식을 바꾸었습니다.
